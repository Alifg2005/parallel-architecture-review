# private-material/

Local-only folder for the original lecture files (PDF, PPTX, …).

- Everything in this folder except this README and `.gitkeep` is ignored by Git.
- Nothing here is imported by the app, copied into `public/`, or included in the Vercel build.
- To add a lecture, drop its file here and give the coding agent the instruction in the root `README.md`
  ("Adding a new lecture").
